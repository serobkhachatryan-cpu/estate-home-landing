Designed for a real estate, not a demo estate

Useful detail
without data sprawl.

  1. 01

    One chosen set of entities

    The administrator selects the total meters, tariff counters and optional feeder meters. The interface does not discover, expose or categorise an entire sensor inventory on its own.

  2. 02

    Recorder-backed weekly history

    Where Home Assistant Recorder retains an approved cumulative sensor, the card derives Monday–Sunday weekly deltas from that local history.

  3. 03

    Cost only when the evidence supports it

    GBP is displayed only from approved cumulative monetary counters with valid coverage. Unavailable or misaligned data is described plainly, not estimated into a false number.

  4. 04

    Read-only by design

    The card presents information. It does not call Home Assistant services, operate devices, relay credentials or publish a property’s telemetry to this website.

A practical release path

Prove the picture.
Then widen it.

A good estate view begins with source topology and data quality, not with a promise to make every sensor visible on day one.

01

Map

Agree the small, named group of total meters, tariff counters and independent feeders that have operational meaning.

02

Validate

Check units, resets, Recorder coverage, missing days and whether a feeder is part of a total or an independent supply.

03

Release

Install the card as a standard Lovelace resource and place it beside existing Home Assistant cards—not above them.

04

Review

Use the weekly rhythm to decide which system, tariff or source relationship deserves the next piece of work.

Questions, answered plainly

What Oriel is
and is not.

Is the public Oriel page connected to a Home Assistant installation?+

No. This public page is a product explanation and visual demonstration. It has no Home Assistant credentials, real-time connection or property telemetry.

Does Oriel replace Home Assistant?+

No. Oriel is designed as a custom Lovelace card or panel within an existing Home Assistant deployment. It presents a focused operational view alongside the administrator’s established dashboards.

Can every sensor appear in the card?+

Not by default. An estate may have hundreds of entities, many of which are diagnostics, controls or private signals. Oriel uses an explicit allowlist so the configured view remains meaningful and reviewable.

Are money values inferred from a tariff?+

Not in the production card. Historical cost is shown only when there are approved, cumulative monetary counters with adequate coverage; otherwise the card keeps the measurement and makes the absence of cost data clear.
